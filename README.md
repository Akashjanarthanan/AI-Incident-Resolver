# AI Incident Resolver

## Problem Statement

IT support teams spend significant time investigating recurring
technical incidents by manually searching troubleshooting documents,
SOPs, FAQs, and previous incident-resolution records.

The goal of this project is to build an AI-powered Incident Resolver
that uses Retrieval-Augmented Generation (RAG) to identify relevant
technical information and recommend evidence-based resolution steps.

## Example Problem

Input:
"Application is unable to connect to Oracle database after deployment.
Error: ORA-12541."

Expected Output:
- Likely root cause
- Relevant troubleshooting steps
- Recommended resolution
- Supporting evidence
- Source documents
- Confidence level
